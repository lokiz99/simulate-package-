# LogiFlow - 现代物流分发与供应链仿真系统

基于 **React**、**Vite**、**Tailwind CSS**、**Recharts** 与 **Lucide React** 构建的专业交互式物流分发与供应链动态仿真调度平台，支持浏览器 **LocalStorage** 数据持久化。

## 系统核心功能

### 1. 监控驾驶舱 (Dashboard)
- **实时关键指标 (KPI)**：全网订单总量、仓库处理中、干线在途中、妥投送达/回单数、排队积压以及履约达成率。
- **动态交互图表**：
  - 每日订单流向与管线吞吐负荷时序面积图 (Recharts AreaChart)。
  - 各大区分拨中心排队积压 vs 正在分拣负荷对比柱状图 (Recharts BarChart)。
  - 订单实时生命周期流转状态分布环形图 (Recharts Donut Chart)。
- **全网最新流转订单**：实时订单流水展示，支持一键点击弹窗查看数字防伪电子签收单 (POD)。

### 2. 仿真调度控制中心 (Simulation)
- **确定性动力学仿真引擎**：按时钟周期脉冲推演，实时模拟订单录入、入库排队、分拣打包、干线发运、在途进度推移及妥投核发防伪电子签收单的全生命周期。
- **交互控制与时钟倍速**：
  - 启动、暂停、重置以及单步推进时钟周期。
  - 0.5x、1x、2x、5x、10x 时钟推演倍速切换。
  - 每日订单生成频率因子 (5-50 单/日)。
  - 仓库综合处理能力系数 (40%-200%)。
  - 干线车队并发运力规模 (10-80 辆运输车)。
  - 平均干线运输周期 (2-8 刻度)。
  - 激活大区仓储枢纽数量 (2-6 个枢纽)。
- **极端工况与压力测试**：
  - 瞬时订单激增 (+15 笔紧急加急单)。
  - 全国恶劣大雪延误 (分拣效率骤降 50%)。
  - 干线运力断崖短缺 (在途配额压减至 10 台)。
  - 紧急清库排障调度令 (优先发运积压包裹)。
- **实时遥测事件流**：带时间戳与状态级别的动态系统事件流水。

### 3. 订单综合管理与审计 (Orders)
- 订单全属性表格：订单编号、货主企业、目的城市、下单时间、当前状态、优先级、始发分拨港、预计送达、回单核验。
- 支持全文关键字模糊检索、多维度组合筛选（订单状态、优先级层级、所属枢纽）、字段排序以及分页浏览。
- **官方防伪电子签收单 (POD) 弹窗**：交付时间、验收签收人、防伪验证哈希码、完好状态备注、电子签名印记以及打印凭单。
- **自定义订单录入**：向当前供应链管线注入个性化货物包裹。

### 4. 区域仓储中心与分拨枢纽 (Warehouses)
- 华东上海超级枢纽、华北北京智慧物流港、华南广州国际分发港、华中武汉多式联运中心、西南成都陆港枢纽、西北西安丝路集散中心。
- 综合指标监控：额定库容、待分拣排队、正在作业、额定处理速率、累计已发货、当前在岗班组编制以及动态库容负荷仪表盘。

### 5. 全域物流拓扑与干线网络 (Network)
- 交互式矢量 SVG 全域物流路由拓扑地图。
- 枢纽节点动态光晕环与容量指示。
- **实时动态干线物流车流动画**：沿贝塞尔曲线管道依在途订单进度实时穿梭位移。
- 悬停浮层展示各枢纽与终端城市的详细遥测数据与服务辐射关系。

### 6. 数据分析与运营报表 (Reports)
- 履约时效指标、积压滞留诊断以及合规级订单审计导出。
- 历史周期履约流速与积压走势折线图。
- 订单优先级结构占比分布图。
- 区域分拨履约合规性对比矩阵表。
- **一键导出全量 CSV 表格**（包含 UTF-8 BOM 防中文乱码）。

## 运行与构建

```bash
# 安装依赖
npm install

# 启动本地开发服务
npm run dev

# 生产环境打包构建
npm run build

# 预览生产构建结果
npm run preview
```
